ABOUT JOBFLUX

Automating early career discovery

Built to give AI, Machine Learning, and Data Science candidates a clean, direct edge in internship applications.

The Core Architecture

JobFlux works in 5 streamlined phases:

  • Phase 1: Scrapes active search results from supported job portals with custom CSS selectors.
  • Phase 2: Normalizes dates and filters listings within the configured recency window (7 days).
  • Phase 3: Deduplicates records across portals using company, job title, and portal composite keys.
  • Phase 4: Resolves official company domains via headless browser search fallback.
  • Phase 5: Asynchronously crawls careers and contact pages to locate publicly visible HR mailboxes, running syntax and MX verification.

Ethical Scraping & Integrity

JobFlux follows responsible public-web practices:

  • Rate Limiting: Random 1–3s delays between requests and strict per-domain request caps.
  • Robots.txt: Automatic robots policy parsing to respect webmaster guidelines.
  • No SMTP Ping Spam: Stops at DNS MX record confirmation to verify domain mail reception without pinging inboxes.
  • Zero Fabrication: Only displays authentic application URLs collected directly from source portals.
